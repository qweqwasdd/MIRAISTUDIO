Подход

Три правила, по которым собран каждый проект

01 · Смысл

Сначала задача, потом пиксели

Каждый сайт начинается с одного вопроса: что человек должен сделать на странице. Структура, тексты и путь до заявки появляются раньше, чем первый цвет.

02 · Визуал

Свой визуал вместо стоков

Фото в нейросетях в одной архитектуре, анимации на canvas, смонтированные видеопетли. Картинка работает на конкретный бренд, а не встречается на десяти других сайтах.

03 · Код

Работает, а не только выглядит

Макет доводится до живого кода: расчёт цены, выбор дат, запись, адаптив до 320 px. Ссылку можно открыть на телефоне прямо сейчас.

booking.js
// упрощённый пример: расчёт брони
const total = (house, nights, guests) => {
  const base = house.price * nights;
  const extra = Math.max(0, guests - house.cap) * 2500;
  return { sum: base + extra,
           prepay: Math.round((base + extra) * 0.3) };
};

Это реальные проекты?

SmartGlobal Systems — коммерческий проект для заказчика из Казахстана. «Аура», ORLO, ÉCLAT и «Зилант» — концепт-проекты: сделаны без заказчика, чтобы показать подход, но полностью работают, их можно открыть по ссылке.

Какие инструменты?

Figma и Tilda для дизайна, HTML, CSS и чистый JavaScript для кода, нейросети для фото и видео.
